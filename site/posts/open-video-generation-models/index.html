5 Open Video Generation Models You Should Know

Five current model families compared by capabilities, GPU requirements, Mac acceleration, fine-tuning, and community support — November 2026.

Published 2026-11-10 · Updated 2026-11-10

1. Five model families worth knowing

Choosing a local video model now involves more than comparing image quality. Some models generate synchronized sound, some accept several kinds of reference material, and others offer a simpler route to customization on consumer hardware. The useful question is which combination fits the videos you want to make and the machine you already own.

This comparison covers public releases checked on 10 November 2026. It includes permissively licensed models and models with downloadable weights under custom licenses. That distinction matters: access to model weights does not automatically provide unrestricted rights to use or redistribute them.

In model names, B means billion parameters, the learned numerical values inside a model. A checkpoint is a saved set of those weights. A distilled checkpoint is trained to generate with fewer sampling steps; it does not necessarily contain fewer parameters.

2. What is the smallest GPU that can run them?

There is no universal minimum independent of the workflow. Resolution, clip length, numerical precision, and the software implementation all change memory use. The generator also needs supporting components: an encoder interprets the prompt, and a decoder turns the model’s compressed representation into video frames.

Quantization stores weights with fewer bits. Offloading moves components between GPU memory and system memory, sometimes using storage as well. These techniques can make a large model fit a smaller card, with tradeoffs in speed and sometimes output quality. 3. Mac acceleration is available, with different levels of support

Apple Silicon Macs share memory between the CPU and GPU, so their memory figures are not directly equivalent to a PC’s dedicated VRAM. Acceleration commonly uses Metal, Apple’s GPU platform, through either PyTorch’s MPS backend or MLX, Apple’s machine-learning framework. Support must be checked for the exact model and runner.

ModelDocumented Apple Silicon path
Wan2.2The community MLX-Video project lists the 5B and A14B text/image models. This does not establish support for every specialized Wan variant. A user has published a 5B run on a 32GB Mac.
HunyuanVideo-1.5PocketAI’s community MLX conversion recommends at least 24GB unified memory. Its release supports text-to-video only, and its published initial rendering example contains just nine frames. Longer clips need separate validation.
LTX-2.5Official Desktop documentation specifies macOS 26+, limits 32GB Macs to 540p and five seconds, and lists 48GB+ for full local generation. A separate community MLX implementation supports LTX-2.5. These are documented capabilities, not benchmarks conducted here.
MiniMax H3The community h3.c project implements native Metal inference, including text, first/last-frame conditioning, and image/video/audio references. Memory depends on its streaming and execution settings; a single general Mac minimum is not established here.
Kandinsky 6.0Mac acceleration remains unverified in the sources reviewed. The official quick start targets NVIDIA GPUs. A generic suggestion to select MPS is insufficient evidence that the complete pipeline works.

Acceleration also needs a realistic expectation of speed. One published Wan2.2 5B report used a 32GB M5 Mac, an eight-bit generator, and 40 sampling steps: producing 49 frames at 704×1280 took 27 minutes and 20 seconds. That is one user’s configuration, not a general Mac benchmark, but it illustrates why “runs locally” and “comfortable for frequent iteration” are separate considerations. 4. Generation strengths, retraining, and community support

For customization, LoRA, or low-rank adaptation, trains a relatively small set of additional weights while keeping the base model largely frozen. It is a common route to teaching a visual style or subject. Full fine-tuning updates the underlying model more broadly and usually demands substantially more resources.

Community support is most useful when it supplies reusable workflows and maintained trainers. ComfyUI provides a visual, node-based workflow interface; Diffusers is a Python library for building generation pipelines. Their integrations are more concrete evidence of usability than a model’s popularity alone.

Wan2.2: a broad foundation for controlled video workflows

Wan emphasizes lighting, composition, and motion control. Its specialized Animate model handles character animation and replacement, while S2V generates motion driven by supplied speech. These complement the general text/image models; the main video checkpoints do not provide the same joint soundtrack-generation workflow as LTX or H3. Model capabilities.

Official sample video: Watch the Wan2.2 release demo in the developers’ repository.

Its practical advantage is the range of available tools. ComfyUI supplies native workflows, while the community development framework DiffSynth-Studio documents both full training and LoRA training for Wan variants. This makes Wan a reasonable starting point for someone who expects to experiment with custom styles and controls. Adapters still need to match the specific checkpoint. Training support.

HunyuanVideo-1.5: a compact backbone with an official training route

Tencent’s design emphasizes motion coherence and Chinese/English prompt understanding. The 8.3B size makes it an interesting middle ground between small generators and much larger audiovisual systems. Its 480p image-to-video step-distilled checkpoint offers eight- or twelve-step generation, while higher-resolution output uses other checkpoints or super-resolution. Release details.

Official sample videos: Watch the HunyuanVideo-1.5 release demo, or browse additional clips with their input prompts, organized around instruction following, motion, and cinematic aesthetics.

Official code supports continued training and LoRA fine-tuning. Community support also includes ComfyUI, Diffusers, and the Musubi Tuner training toolkit, which has a dedicated HunyuanVideo-1.5 guide. The presence of both official and community training paths makes customization easier to evaluate. Official training; Musubi guide.

LTX-2.5: connected shots and synchronized sound

LTX-2.5 is particularly relevant when a project needs sound and multiple connected shots. Its developer checkpoint supports customization, while its distilled checkpoint provides an eight-step generation path. These capabilities make it a candidate for short sequences with dialogue, ambience, and cuts, though consistency still needs to be judged on the actual output. Capabilities and checkpoints.

Official sample videos: Watch the LTX-2.5 video showcase on Lightricks’ model page, including examples for motion, multi-shot generation, and prompt following.

Lightricks supplies an official trainer for LoRA and full fine-tuning. It also supports IC-LoRA, adapters that condition generation on reference material for controlled transformations. Together with Desktop and ComfyUI integration, this provides a comparatively complete creation-and-customization workflow. Official trainer; Inference tools.

MiniMax H3: flexible reference-guided generation

H3’s distinctive feature is its ability to combine different reference types. A creator can supply images for appearance, video for a reference sequence, and audio as another condition. However, the full hosted system includes a context-processing service and a 2K regeneration stage that the official release does not include. Downloading H3-Base therefore does not reproduce every feature of the hosted product. System architecture and release scope.

Official sample videos: MiniMax publishes three 768p H3-Base examples: text-to-video with audio, first/last-frame conditioning, and multimodal reference conditioning. These MP4 files are linked from the repository’s reproducible examples.

Customization is supported through community tools: DiffSynth-Studio documents full training and LoRA recipes, and Musubi Tuner describes its H3 support as experimental. ComfyUI, Diffusers, quantized packages, and native Mac implementations give it a substantial ecosystem, although the many task variants make configuration more involved. DiffSynth training support; Musubi release notes.

Kandinsky 6.0: a small audiovisual option with developing customization tools

Kandinsky’s 3B Lite model is appealing for experimenting with short clips that include sound. The distilled versions use ten sampling steps, and the separate super-resolution model makes the distinction between base generation and Full HD output explicit. Its October 2026 release already has Diffusers and ComfyUI integrations. Release and integrations.

Official sample videos: Watch the Kandinsky 6.0 showreel and sample gallery. Look for the section labeled “Generated with Kandinsky 6.0 Video”; the page also includes examples from the previous 5.0 release.

The research paper demonstrates LoRA-based post-training, so adaptation is technically established. However, a ready-to-use, maintained public LoRA training workflow for version 6 was not verified in the reviewed sources. The older Kandinsky 5 trainer should not be assumed compatible. For a creator whose immediate goal is a custom character adapter, this tooling gap matters more than the attractive 3B parameter count. Training methodology.

5. Choosing a starting point

Based on the documented capabilities and tooling, the most useful shortlist depends on the work:

  • General video generation and customization: start by evaluating Wan2.2. Its range of variants and training integrations provides room to grow.
  • A moderately sized model with official fine-tuning support: consider HunyuanVideo-1.5.
  • Connected shots with generated sound: evaluate LTX-2.5, especially when its Desktop workflow fits your hardware.
  • Generation guided by several reference types: consider MiniMax H3, allowing time to understand its task-specific workflows.
  • Short audiovisual experiments with a small generator: try Kandinsky 6.0 Lite, while treating custom training as a less established path.

For an existing low-memory NVIDIA GPU, Wan’s 5B ComfyUI workflow offers a clearly documented starting point. Mac users have several acceleration paths, but should choose the implementation as carefully as the model. Anyone planning to train adapters should evaluate the trainer before purchasing hardware.

The field now offers meaningful choices in sound, reference control, and local customization. Parameter count helps describe those choices, but the better model is the one whose complete workflow gives you the control, turnaround time, and licensing terms your project needs.
